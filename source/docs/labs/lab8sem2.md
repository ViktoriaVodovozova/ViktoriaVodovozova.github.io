### Цель работы:
Освоение методов скрапинга данных из веб-страниц на примере сайта news.itmo.ru.

### Структура данных :
- Идентификатор новости (целочисленное число из URL)
- Название новости
- Дата её размещения
- URL на страницу с конкретной новостью.

### Выполненные задачи:
1. Сбор данных через поиск: Реализован поиск новостей по ключевым словам. Извлечены заголовки и URL всех найденных новостей Использован селектор li.weeklyevent для поиска элементов
2. Детальный парсинг каждой новости:
- Идентификатор - извлекается из URL с помощью регулярного выражения r'/(\d+)/?$'
- Название новости — получено из поисковой выдачи
- Дата размещения — Поиск тега внутри блока с классом time.
- Количество просмотров — поиск по классу views или тексту с числовым значением
- Текст новости — реализована вариативность парсинга через несколько селекторов: news_text, article-content, content, article
- Теги — извлекаются из блоков div.tags или div.news-tags
3. Сохранение данных: Основной CSV файл scraped_news_data.csv содержит все данные в одной таблице Папка news_content содержит отдельные CSV файлы для каждой новости (формат: news_{ID}.csv)

### Технические особенности:
Защита от блокировки: задержки между запросами 1-2 секунды с использованием random.randint()
