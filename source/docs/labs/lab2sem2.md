## NumPy Lab - Quick Reference

### Основные методы
- Создание: `np.arange()`, `np.random.rand()`, `.reshape()`
- Операции: `+`, `*`, `@`, `np.dot()`, `.T`
- Линейная алгебра: `np.linalg.det()`, `.inv()`, `.solve()`
- Статистика: `mean()`, `median()`, `std()`, `percentile()`
- Нормализация: `(x - min) / (max - min)`
